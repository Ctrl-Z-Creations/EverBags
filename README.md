# EverBags

One-window, categorized bags and bank for **World of Warcraft: Forever**.

By [Ctrl+Z Dev](https://github.com/Ctrl-Z-Dev).

## Install

Get it from CurseForge or Wago, or download the zip from [Releases](https://github.com/Ctrl-Z-Dev/EverBags/releases) and unzip it into your WoW: Forever `Interface\AddOns` folder.

## Releasing (for me)

1. Add an entry to `CHANGELOG.md`.
2. Commit, then create a tag like `v0.6.0` and push it.
3. GitHub Actions builds the zip and uploads it to GitHub Releases, CurseForge and Wago.

Tags with `alpha` or `beta` in them (e.g. `v0.6.0-beta1`) are published as test builds instead of full releases.
